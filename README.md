# 📚 Biblioteca Digital (Full Stack)

Projeto de desenvolvimento web full stack desenvolvido como uma aplicação de estudos para gerenciamento
de uma biblioteca digital. O sistema permite cadastrar novos livros, 
listá-los em tempo real a partir de um banco de dados relacional e excluí-los conforme a necessidade.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias:

* **Front-end:** HTML5, CSS3 e JavaScript (Vanilla / Fetch API)
* **Back-end:** Python com [Flask](https://flask.palletsprojects.com/)
* **Banco de Dados:** SQLite3
* **Gerenciamento de Ambiente:** Ambiente Virtual do Python (`.venv`)

---

## ⚙️ Pré-requisitos

Certifique-se de ter instalado em sua máquina:
* [Python](https://www.python.org/) (versão 3.x recomendada)
* Um editor de código, como o [VS Code](https://code.visualstudio.com/)

---

📌 Funcionalidades
Cadastro de Livros: Insira o título, autor e ano de publicação de um livro através do formulário web.

Listagem Dinâmica: Os livros cadastrados são salvos no banco de dados SQLite e exibidos automaticamente na tela.

Exclusão de Registros: Cada livro listado possui um botão de exclusão que remove o item instantaneamente do banco de dados e atualiza a interface.
